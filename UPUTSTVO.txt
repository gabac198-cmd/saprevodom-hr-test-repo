SaPrevodom HR test - v20 (titlovi izravno sa izvora)
====================================================
SADRZAJ PAKETA (3 datoteke - sve idu U KORIJEN (main) tvog GitHub repoa):
  1) repo.json
  2) plugins.json
  3) SaPrevodomHrTest.cs3

KAKO INSTALIRATI
----------------
A) AKO KORISTIS GITHUB REPO (gabac198-cmd/saprevodom-hr-test-repo):
   - repo.json i plugins.json: klikni olovku (Edit) -> Ctrl+A -> obrisi -> zalijepi
     novi sadrzaj -> Commit changes.
   - SaPrevodomHrTest.cs3 (binarna datoteka): Add file > Upload files.
   - Imena moraju ostati ISTA.

B) AKO KORISTIS IZRAVNI LINK (bez GitHuba):
   - U CloudStreamu: Settings > Extensions > Add repository
   - Zalijepi link do repo.json (vidi poruku uz isporuku).

U APLIKACIJI
------------
Instaliraj: SaPrevodom (Filmovi/Serije) HR test
Otvori film/seriju > play > Subtitle > odaberi:
  HRVATSKI (Croatian / Croatian +), SRPSKI (Serbian / Serbian +), BOSANSKI (Bosnian)

NOVO U v20
----------
Titlovi se sada uzimaju IZRAVNO sa izvornog playera (cisti UTF-8), pa nema vise
problema sa starim CP1250 kodiranjem (kvacice se prikazuju ispravno).
Ako izvor nema svoj titl, automatski se koristi rezervna pretraga.
